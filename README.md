# Tu diseño, tu prenda — vista de demostración

Maqueta estática para compartir el aspecto y el configurador de la tienda. No recopila datos personales, no sube diseños, no envía pedidos y no se conecta al servidor Node.

## Archivos

- `index.html`: página de demostración.
- `styles.css`: estilos adaptables a móvil.
- `preview.js`: controles visuales y cálculo orientativo solo para camiseta con impresión pequeña.
- `prendas-hero.png`: imagen de prendas.

La camiseta se muestra a 7 € con un diseño pequeño incluido y 1 € por cada diseño pequeño adicional, conforme a la configuración inicial solicitada. No hay precios para polos, sudaderas ni impresión grande. Las tallas y sus medidas verificadas siguen pendientes de configurar.
